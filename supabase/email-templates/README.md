# Workshido — Supabase auth email templates

Paste each file into Supabase → Authentication → Emails → Templates (custom SMTP via Resend).
Plain HTML, no images or tracking, so they stay out of spam folders.

| Template | Subject | File |
|---|---|---|
| confirmation | Confirm your Workshido account | `confirmation.html` |
| recovery | Reset your Workshido password | `recovery.html` |
| magic_link | Your Workshido sign-in link | `magic_link.html` |
| email_change | Confirm your new email for Workshido | `email_change.html` |
