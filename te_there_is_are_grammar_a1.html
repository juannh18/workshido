Answer Key
Exercise 1 – Grammar Box (Read and Study)
No answers needed. Students read the rule: there is + singular noun / there are + plural noun / there isn't, there aren't for negatives.
Exercise 2 – Complete the Sentences (there is / there are)
1. There is a lamp on the desk.
2. There are three shelves on the wall.
3. There is a garden in front of the house.
4. There are two bathrooms in the apartment.
5. There is some milk in the fridge.
6. There is a cat under the table.
7. There are four students in the classroom.
8. There are a lot of people in the park.
9. There is a car in the garage.
10. There isn't any sugar in the jar.
Item 10 uses "any," which signals the negative form even though the instruction line only mentions is/are — a good teaching moment (see Teacher Tip).
Exercise 3 – Look at the Pictures and Write Sentences
Open task — accept any sentence that correctly describes each picture. Suggested models (2 sentences each):
  • 1. Kitchen — There is a stove in the kitchen. There are some oranges on the table.
  • 2. Living room — There is a TV in the living room. There is a plant next to the TV.
  • 3. Bedroom — There is a bed in the bedroom. There is a lamp next to the bed.
  • 4. Bookshelf — There are many books on the shelf. There is a plant on the shelf.
  • 5. Bathroom — There is a sink in the bathroom. There is a mirror above the sink.
Exercise 4 – Write Negative Sentences (there isn't / there aren't)
  • 1. There isn't any fish.
  • 2. There aren't any bikes.
  • 3. There isn't any cake.
  • 4. There aren't any trees.
  • 5. There aren't any keys.
Exercise 5 – Read and Answer (Tom's House)
  • 1. How many sofas are there in the living room? — There are two sofas.
  • 2. Is there a kitchen in the house? — Yes, there is.
  • 3. How many bedrooms are there? — There are three bedrooms.
  • 4. Is there a garden? — Yes, there is. (a small garden behind the house)
  • 5. Are there any cars? — No, there aren't.
  • 6. What are there in the garden? — There are two bicycles.
Extra Challenge (suggested)
Personal — accept any 3 correct sentences about the classroom.
There is a board in the classroom. There are twenty desks. There are some windows.
Teacher Tip
Drill the core rule first: there is + singular/uncountable noun, there are + plural noun. For Ex 2 item 10, point out that "any" is the giveaway word for negatives and questions ("There isn't any sugar," not "There is any sugar") — a common A1 trap worth flagging explicitly. For Ex 5, have students underline the sentence in the text that proves each answer before writing it.
Common Student Mistakes
✗ There is two chairs.
✓ There are two chairs.
✗ There are a cat under the table.
✓ There is a cat under the table.
✗ There not a garden.
✓ There isn't a garden.
✗ There is any sugar.
✓ There isn't any sugar. (any → negative)
Teacher Extra Activity
Classroom Scavenger Hunt (10 min)
In pairs, students list 8 things they can see in the classroom using "There is / There are." Then they swap lists with another pair and check if the sentences are true (T) or false (F) for the room. Reinforces both form and meaning.

Lesson Plan (45 minutes)
TimeStageProcedure
5 minWarm-UpShow a picture of a room (or use the worksheet header image). Ask: "What can you see?" Elicit objects in L1/L2 to activate vocabulary before introducing the target structure.
10 minPresentationGo through the Grammar Box (Ex 1) on the board. Highlight the singular/plural rule and the negative forms. Drill chorally: "There is a sofa. There are two chairs."
10 minControlled PracticeStudents complete Ex 2 individually, then check answers in pairs before whole-class correction. Pay special attention to item 10 (any → negative).
10 minGuided PracticeStudents complete Ex 3 (picture description) and Ex 4 (negatives) in pairs, taking turns reading sentences aloud to each other.
8 minReading & ProductionStudents read the short text in Ex 5 and answer the questions individually, then compare answers with a partner.
2 minWrap-UpQuick exit check: each student says one true sentence about the classroom using "There is / There are." Assign Extra Challenge as homework if time runs short.
