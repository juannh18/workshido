Answer Key
Exercise 1 – Sentence Builder
There Is (singular):
  • 1. There is a table in the room.
  • 2. There is a plant on the table.
  • 3. There is a chair next to the table.
  • 4. There is a book on the table.
There Are (plural):
  • 1. There are three stools in the kitchen.
  • 2. There are some cups on the shelf.
  • 3. There are two windows in the kitchen.
  • 4. There are some plants on the shelf.
Exercise 2 – Guided Writing (5 pictures, open)
Accept any correct sentences describing each picture. Suggested models (2 sentences each):
  • 1. Park — There are many trees in the park. There is a bench on the path.
  • 2. Classroom — There is a whiteboard in the classroom. There are many desks.
  • 3. Bathroom — There is a sink in the bathroom. There is a mirror above the sink.
  • 4. Bedroom — There is a bed in the bedroom. There is a lamp next to the bed.
  • 5. Bookshelf — There are many books on the shelf. There is a plant on the shelf.
Exercise 3 – Write About This Place (open, 5–6 sentences)
Accept any correct description of the living/dining room picture. Suggested model:
There is a dining table with four chairs. There is a sofa in the living room. There is a TV on the stand. There are two pictures on the wall. There are two pendant lights above the table. There is a plant next to the window.
Exercise 4 – Free Writing (personal, 6–8 sentences)
Open — accept any grammatically correct paragraph about the student's favorite room or classroom. Suggested model:
My favorite room is my bedroom. There is a big bed next to the window. There is a desk with a lamp. There are some books on the shelf. There is a mirror on the wall. There are two pictures above the bed. There is a rug on the floor. I love spending time in my room.
Teacher Tip
For Ex 1, write the two column headers (THERE IS / THERE ARE) on the board first and elicit a few examples before students write independently — this prevents singular/plural mix-ups early. For Ex 4, give students the Useful Words box time before they start: brainstorming "next to / under / behind" together raises the quality of the final paragraph noticeably.
Common Student Mistakes
✗ There is three stools.
✓ There are three stools.
✗ There are a plant on the table.
✓ There is a plant on the table.
✗ There is books on the shelf.
✓ There are books on the shelf.
✗ Have a sofa in the room.
✓ There is a sofa in the room.
Teacher Extra Activity
Describe and Draw (10–15 min)
In pairs, Student A writes 5 "There is / There are" sentences describing an imaginary room (without showing the partner). Student B listens and draws the room based only on the sentences. Compare the drawing to what Student A imagined — great for checking clarity and accuracy of writing.
